# acme-support-bot (sample connected repo)

The demo codebase Driftwatch's Impact Graph scans: a support bot calling NimbusAI models
(`nimbus-large-2`, `nimbus-vision-1`) and the PayFlux API (`/v2/charges`, `/v2/refunds`,
`/v1/tokens`). `usage.yaml` declares monthly token volumes for cost-delta estimation.
